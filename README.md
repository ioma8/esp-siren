# ESP32 police siren

This sketch alternates 900 Hz and 600 Hz tones indefinitely on GPIO25. The
onboard LED blinks in sync with the tone changes, using the board's
`LED_BUILTIN` definition or GPIO2 on common ESP-WROOM-32 DevKit boards.

The same firmware is also implemented in Rust with `esp-hal` under `src/`.

Connect a passive buzzer or small piezo speaker between GPIO25 and GND. The
GPIO25 output is generated by the ESP32 Arduino `tone()` function or the Rust
LEDC driver.

## Board

Target board: ESP-WROOM-32 / generic ESP32 Dev Module

## Build and flash

```sh
arduino-cli compile --fqbn esp32:esp32:esp32 .
arduino-cli upload -p /dev/cu.<esp32-port> --fqbn esp32:esp32:esp32 .
```

## Rust build and flash

The Rust version targets the classic Xtensa ESP32:

```sh
source ~/export-esp.sh
cargo build --release
espflash flash --monitor --chip esp32 target/xtensa-esp32-none-elf/release/esp-siren
```

Or run the complete build-and-flash flow directly:

```sh
./flash.sh
```

Override the serial port when needed with `ESP32_PORT=/dev/cu.usbserial-XXXX
./flash.sh`.

Install the required tools with `cargo install espup --locked` followed by
`espup install`, and install `espflash` with `cargo install espflash --locked`.

A passive, high-impedance piezo speaker is suitable; do not connect a
low-impedance powered speaker directly to the GPIO. Use an amplifier/transistor
stage for a larger speaker.

## Wokwi browser simulation

The project includes [diagram.json](diagram.json) and [wokwi.toml](wokwi.toml)
for Wokwi. Build the Rust ELF locally first:

```sh
source ~/export-esp.sh
RUSTUP_TOOLCHAIN=esp cargo build --release
```

Then open the [Wokwi ESP32 project template](https://wokwi.com/projects/new/esp32)
in a browser. Replace its `diagram.json` with this project's
[diagram.json](diagram.json), press `F1`, choose **Upload Firmware and Start
Simulation**, and select:

```text
target/xtensa-esp32-none-elf/release/esp-siren
```

The virtual buzzer is connected to GPIO25 and GND. Wokwi does not render the
physical DevKit's onboard LED, so the diagram includes an explicit blue LED on
GPIO2 to show the same signal.
